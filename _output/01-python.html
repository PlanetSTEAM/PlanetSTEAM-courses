Python Basics & Fundamentals

Python es un lenguaje de programación interpretado, dinámico y de alto nivel. Creado por Guido van Rossum en 1991, se ha convertido en uno de los lenguajes más populares para desarrollo general, ciencia de datos y automatización.

Por qué Python?

  • Legibilidad: Sintaxis clara y simple
  • Versátil: Web, data science, ML, automatización
  • Comunidad: Miles de librerías (pip)
  • Demanda: Top 3 en ofertas laborales LATAM

Exercises

Ejercicio 1: Variables y Strings

Crea variables para nombre, edad y ciudad. Imprime un saludo personalizado.

Solución: \ nombre = ‘Juan’ edad = 25 ciudad = ‘Lima’ print(f’Hola {nombre}, tienes {edad} años y vives en {ciudad}’) \

Hint: Usa f-strings para interpolación

Ejercicio 2: Operaciones Matemáticas

Calcula el promedio de 5 números.

Solución: \ numeros = [87, 92, 78, 95, 88] promedio = sum(numeros) / len(numeros) print(f’Promedio: {promedio:.2f}’) \

Hint: Usa sum() y len()

Ejercicio 3: Conversión de Tipos

Convierte edad de string a entero y suma 10.

Solución: \ edad_str = input(‘Tu edad:’) edad = int(edad_str) edad_futura = edad + 10 print(f’En 10 años: {edad_futura}’) \

Hint: Usa int() para conversión

Practical Project

Proyecto: Calculadora de IMC

Crea un programa que calcule el IMC de una persona.

Requisitos: 1. Solicita peso (kg) y altura (metros) 2. Calcula: IMC = peso / (altura²) 3. Muestra categoría (bajo peso, normal, sobrepeso, obeso)

Código base: \ peso = float(input(‘Tu peso (kg):’)) altura = float(input(‘Tu altura (m):’))

imc = peso / (altura ** 2) print(f’Tu IMC: {imc:.2f}’)

if imc < 18.5: print(‘Bajo peso’) elif imc < 25: print(‘Peso normal’) elif imc < 30: print(‘Sobrepeso’) else: print(‘Obeso’) \

Objetivos: ✓ Input del usuario ✓ Cálculos matemáticos ✓ Condicionales (if/elif/else) ✓ Formateo de output
