FUNDAMENTOS (Módulos 1-4)

Módulo 1: ¿Qué es Python? + Setup Profesional (2h)

  • Por qué Python para Data Analysis
  • Instalación Python 3.11+
  • VS Code setup
  • Librerías esenciales (Pandas, NumPy, Matplotlib)
  • Estructura profesional de proyecto
  • Requirements.txt + README

Módulo 2: Variables y Tipos de Datos (3h)

  • Strings: manipulación de texto
  • Integers: números enteros
  • Floats: números decimales
  • Booleans: operadores lógicos
  • Type conversion & casting
  • Proyecto: Calculadora de salario con impuestos

Módulo 3: Control Flow (3h)

  • if / elif / else decisiones
  • Operadores de comparación (>, <, ==, !=)
  • Operadores lógicos (and, or, not)
  • while loops
  • for loops
  • break & continue
  • Proyecto: Juego “Adivina el número”

Módulo 4: Funciones y Módulos (3h)

  • Definir funciones (def)
  • Parámetros y argumentos
  • Return values
  • Scope (local vs global)
  • Importar módulos
  • Crear funciones reutilizables
  • Proyecto: Suite de utilidades para análisis

ANÁLISIS DE DATOS (Módulos 5-9)

Módulo 5: Introducción a Pandas (4h)

  • Series: estructura 1D
  • DataFrames: tablas (filas × columnas)
  • Carga datos: read_csv(), read_excel()
  • Explorar: head(), tail(), info(), describe()
  • Seleccionar datos: [], loc[], iloc[]
  • Filtrar datos con condiciones
  • Proyecto: Cargar y explorar dataset de ventas

Módulo 6: Exploratory Data Analysis (EDA) (4h)

  • Estadísticas descriptivas (describe())
  • Frecuencias (value_counts())
  • Detectar y remover duplicados
  • Manejar datos faltantes (NaN)
  • Correlaciones entre variables
  • groupby(): agrupar y agregar
  • Proyecto: EDA completo de dataset de clientes

Módulo 7: Visualización con Matplotlib/Seaborn (4h)

  • Line plots: tendencias temporales
  • Bar charts: comparaciones categorías
  • Histograms: distribuciones de frecuencia
  • Scatter plots: correlaciones bivariadas
  • Heatmaps: matrices de correlación
  • Personalización: colores, estilos, anotaciones
  • Proyecto: Dashboard con 5 gráficos profesionales

Módulo 8: SQL para Analistas (3h)

  • SELECT básico
  • WHERE: filtros
  • ORDER BY, LIMIT
  • JOINs: INNER, LEFT, RIGHT
  • GROUP BY, HAVING, agregaciones
  • Subqueries
  • Proyecto: Queries reales contra PostgreSQL

Módulo 9: Estadística Básica para Datos (3h)

  • Medidas centrales: media, mediana, moda
  • Medidas de dispersión: desv. estándar, varianza
  • Distribuciones de probabilidad
  • Correlación de Pearson
  • Regresión lineal simple
  • Tests de hipótesis básicos
  • Proyecto: Análisis estadístico profundo
