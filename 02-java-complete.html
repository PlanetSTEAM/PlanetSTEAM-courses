Code Examples:

// JVM Architecture Understanding
public class JVMBasics {
    // Static variables (Class/Metaspace)
    static int counter = 0;

    // Instance variable (Heap)
    private String name;

    public static void main(String[] args) {
        // Stack allocation
        int age = 25;
        String city = "Lima";

        // Object creation (Heap)
        Person person = new Person("Alice", 30);

        // Garbage collection demo
        demonstrateGC();
    }

    static void demonstrateGC() {
        Person temp = new Person("Bob", 28);
        // temp goes out of scope, eligible for GC
    }
}

class Person {
    String name;
    int age;

    Person(String name, int age) {
        this.name = name;
        this.age = age;
    }
}

// Switch Expression (Java 12+)
public class ModernJava {
    public static void main(String[] args) {
        String day = "MONDAY";

        String type = switch(day) {
            case "MONDAY", "TUESDAY", "WEDNESDAY", "THURSDAY", "FRIDAY" -> "WEEKDAY";
            case "SATURDAY", "SUNDAY" -> "WEEKEND";
            default -> "INVALID";
        };

        System.out.println(type); // Output: WEEKDAY
    }
}

// Method Overloading Example
public class Calculator {
    public int add(int a, int b) {
        return a + b;
    }

    public double add(double a, double b) {
        return a + b;
    }

    public int add(int... numbers) { // Varargs
        int sum = 0;
        for (int num : numbers) {
            sum += num;
        }
        return sum;
    }
}

// Recursion Example
public class Recursion {
    // Factorial calculation
    static int factorial(int n) {
        if (n <= 1) return 1;
        return n * factorial(n - 1);
    }

    // Fibonacci sequence
    static int fibonacci(int n) {
        if (n <= 1) return n;
        return fibonacci(n - 1) + fibonacci(n - 2);
    }
}

Knowledge Check (3 Questions):

  1. Question 1: What is the difference between stack and heap memory in Java?

      1. Stack stores primitives only; Heap stores objects
      1. Stack stores local variables and method calls; Heap stores all objects
      1. Heap is faster than stack
      1. Stack is used for garbage collection

    Answer: B Explanation: Stack memory is allocated per thread for local variables and method execution. Heap is shared and stores all objects. Stack is automatically freed when methods exit; Heap is managed by garbage collector.

  2. Question 2: What will this code print?

    String result = switch("JAVA") {
    case "JAVA" -> "Programming Language";
    case "SQL" -> "Query Language";
    default -> "Unknown";
};
System.out.println(result);
      1. Programming Language
      1. Query Language
      1. Unknown
      1. Compilation Error

    Answer: A Explanation: Switch expression matches “JAVA” with first case and returns “Programming Language”.

  3. Question 3: What is the output of this method call?

    int result = add(1, 2, 3, 4, 5);

    (Using varargs method: public int add(int... numbers))

      1. 1
      1. 5
      1. 15
      1. Compilation Error

    Answer: C Explanation: Varargs accepts multiple arguments. Method sums 1+2+3+4+5 = 15.
