📚 Module Structure (Each Module: 4-8 hours)

Module 1: Data Engineering Fundamentals

Learning Objectives: - Understand data pipeline architecture - Master ETL vs ELT concepts - Learn data quality and governance - Explore distributed computing basics

Theory & Concepts:

1. ETL/ELT Fundamentals
   - Extract (data sources, APIs, databases)
   - Transform (data cleaning, enrichment, aggregation)
   - Load (data warehouses, data lakes)

2. Distributed Systems
   - MapReduce concepts
   - Data partitioning and sharding
   - Eventual consistency

3. Data Quality & Governance
   - Data validation and cleansing
   - Master data management
   - Data lineage and metadata

4. Architecture Patterns
   - Batch processing
   - Stream processing
   - Lambda and Kappa architectures

Code Examples:

# Apache Spark Example
from pyspark.sql import SparkSession

spark = SparkSession.builder.appName("DataPipeline").getOrCreate()

# Read data
df = spark.read.csv("s3://bucket/data.csv", header=True)

# Transform
df_clean = df.dropna().filter("age > 18")
df_aggregated = df_clean.groupBy("category").count()

# Write
df_aggregated.write.mode("overwrite").parquet("s3://bucket/output/")

# SQL
df.createOrReplaceTempView("users")
result = spark.sql("SELECT category, COUNT(*) FROM users GROUP BY category")

# Kafka Producer Example
from kafka import KafkaProducer
import json

producer = KafkaProducer(
    bootstrap_servers=['localhost:9092'],
    value_serializer=lambda v: json.dumps(v).encode('utf-8')
)

producer.send('transactions', {
    'user_id': 123,
    'amount': 99.99,
    'timestamp': '2026-08-15T10:30:00Z'
})
