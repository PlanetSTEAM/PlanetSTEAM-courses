Module 4: Functions & Methods

Duration: 6 hours | Level: Beginner

Learning Objectives

  • Define and call functions with parameters
  • Use default arguments and *args, **kwargs
  • Implement return values and None
  • Apply decorators for function enhancement

Theory & Concepts

  • Function Basics: def, parameters, return values
  • Arguments: Positional, keyword, defaults, *args, **kwargs
  • Scope: Local, global, nonlocal variables
  • Decorators: Function wrappers, common decorators

Code Examples

# Basic Function
def greet(name, greeting="Hello"):
    return f"{greeting}, {name}!"

# Args and Kwargs
def calculate(*args, **kwargs):
    total = sum(args)
    operation = kwargs.get('op', 'sum')
    return total

# Decorator Example
def timer(func):
    def wrapper(*args, **kwargs):
        import time
        start = time.time()
        result = func(*args, **kwargs)
        print(f"Took {time.time() - start} seconds")
        return result
    return wrapper

Exercises

Code Examples

import logging

logging.basicConfig(level=logging.DEBUG)

    logger.error("Cannot divide by zero")
finally:
    logger.info("Operation complete")

Module 8: Advanced Topics

Duration: 7 hours | Level: Advanced

Learning Objectives

  • Master async/await for concurrent programming
  • Use generators and iterators
  • Implement context managers
  • Apply functional programming concepts

Theory & Concepts

  • Async/Await: asyncio, event loop, concurrent tasks
  • Generators: yield, generator expressions
  • Context Managers: with statement, enter, exit
  • Functional: map, filter, reduce, lambda, functools

Code Examples

# Async Example
import asyncio

async def fetch_data(url):
    await asyncio.sleep(1)  # Simulating I/O
    return f"Data from {url}"

async def main():
    results = await asyncio.gather(
        fetch_data("url1"),
        fetch_data("url2")
    )

# Generator Example
def count_up_to(n):
    i = 0
    while i < n:
        yield i
        i += 1

# Context Manager
with open("file.txt") as f:
    data = f.read()
