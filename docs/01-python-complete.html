1.5.4.3 Code Examples

# Basic Function
def greet(name, greeting="Hello"):
    return f"{greeting}, {name}!"

# Args and Kwargs
def calculate(*args, **kwargs):
    total = sum(args)
    operation = kwargs.get('op', 'sum')
    return total

# Decorator Example
def timer(func):
    def wrapper(*args, **kwargs):
        import time
        start = time.time()
        result = func(*args, **kwargs)
        print(f"Took {time.time() - start} seconds")
        return result
    return wrapper

1.5.8.3 Code Examples

# Async Example
import asyncio

async def fetch_data(url):
    await asyncio.sleep(1)  # Simulating I/O
    return f"Data from {url}"

async def main():
    results = await asyncio.gather(
        fetch_data("url1"),
        fetch_data("url2")
    )

# Generator Example
def count_up_to(n):
    i = 0
    while i < n:
        yield i
        i += 1

# Context Manager
with open("file.txt") as f:
    data = f.read()

- **Arguments:** Positional, keyword, defaults, *args, **kwargs
- **Scope:** Local, global, nonlocal variables
- **Decorators:** Function wrappers, common decorators

#### Code Examples
```python
# Basic Function
def greet(name, greeting="Hello"):
    return f"{greeting}, {name}!"

# Args and Kwargs
def calculate(*args, **kwargs):
    total = sum(args)
    operation = kwargs.get('op', 'sum')
    return total

# Decorator Example
def timer(func):
    def wrapper(*args, **kwargs):
        import time
        start = time.time()
        result = func(*args, **kwargs)
        print(f"Took {time.time() - start} seconds")
        return result
    return wrapper
```


### Module 8: Advanced Topics
**Duration:** 7 hours | **Level:** Advanced

#### Learning Objectives
- Master async/await for concurrent programming
- Use generators and iterators
- Implement context managers
- Apply functional programming concepts

#### Theory & Concepts
- **Async/Await:** asyncio, event loop, concurrent tasks
- **Generators:** yield, generator expressions
- **Context Managers:** with statement, __enter__, __exit__
- **Functional:** map, filter, reduce, lambda, functools

#### Code Examples
```python
# Async Example
import asyncio

async def fetch_data(url):
    await asyncio.sleep(1)  # Simulating I/O
    return f"Data from {url}"

async def main():
    results = await asyncio.gather(
        fetch_data("url1"),
        fetch_data("url2")
    )

# Generator Example
def count_up_to(n):
    i = 0
    while i < n:
        yield i
        i += 1

# Context Manager
with open("file.txt") as f:
    data = f.read()
```
